# Gestión de Cuentas de Usuarios en Linux

Esta guía cubre todo el ciclo de vida de un usuario en Linux utilizando un único ejemplo práctico de principio a fin: el usuario **`hugofrias`**.

>[!NOTE]
> 💡 **Nota:** La administración de cuentas de usuario requiere privilegios de superusuario (`sudo`).

---

## 1. ¿Dónde Guarda Linux la Información de los Usuarios?

Linux registra las cuentas en tres archivos de configuración fundamentales:

1. **/etc/passwd:** Contiene los datos principales de la cuenta (nombre, identificador UID, grupo GID, carpeta personal y shell). Es legible por cualquier usuario.
2. **/etc/shadow:** Guarda los hashes cifrados de las contraseñas y las fechas de expiración. Solo `root` tiene acceso de lectura.
3. **/etc/group:** Almacena los grupos creados en el sistema y qué usuarios pertenecen a ellos.

---

## 2. Creación de la Cuenta: `useradd` vs `adduser`

Existen dos herramientas para dar de alta al usuario **`hugofrias`**:

### Opción A: Con `useradd` (El estándar universal en servidores)

Es el comando base de bajo nivel disponible en todas las distribuciones. No asume nada por defecto, así que debemos indicarle que cree su carpeta personal con `-m` y asigne su terminal con `-s`:

```bash
# -m: Crea físicamente su carpeta /home/hugofrias
# -s: Define su shell inicial (/bin/bash)
sudo useradd -m -s /bin/bash hugofrias
```

>[!WARNING]
> ⚠️ **Cuidado:** Si ejecutas `sudo useradd hugofrias` sin la bandera `-m`, la cuenta existirá pero **sin carpeta personal**. Al iniciar sesión, el sistema mostrará un error y lo arrojará a la raíz (`/`).

### Opción B: Con `adduser` (Asistente interactivo en Debian/Ubuntu)

Es un script que te guía paso a paso, crea la carpeta `/home/hugofrias` por ti y te pide la contraseña al instante:

```bash
sudo adduser hugofrias
```

## 3. ¿Cómo Comprobar si se Creó y Dónde Está su Carpeta?

Nunca asumas que el comando terminó bien sin comprobar el sistema:

### 3.1. Consultar su registro en `/etc/passwd`

```bash
grep hugofrias /etc/passwd
```

**Salida desglosada:**

```text

hugofrias:x:1001:1001:Hugo Frias:/home/hugofrias:/bin/bash
    ┬     ┬   ┬    ┬       ┬            ┬             ┬
    1     2   3    4       5            6             7
```

1. **Usuario:** `hugofrias`

2. **Contraseña:** `x` (protegida dentro de `/etc/shadow`)
3. **UID (User ID):** Identificador numérico del usuario (`1001`)
4. **GID (Group ID):** Identificador de su grupo primario (`1001`)
5. **Comentario/Datos:** Nombre o descripción
6. **Carpeta personal:** `/home/hugofrias`
7. **Intérprete de comandos:** `/bin/bash`

### 3.2. Verificar físicamente su carpeta personal

Comprobamos que la carpeta exista en el disco y que pertenezca a **`hugofrias`** y no a `root`:

```bash
ls -ld /home/hugofrias
# Salida esperada:
# drwxr-x--- 2 hugofrias hugofrias 4096 mar 25 10:00 /home/hugofrias
```

### 3.3. Ver su identidad y grupos con `id`

```bash
id hugofrias
# Salida: uid=1001(hugofrias) gid=1001(hugofrias) groups=1001(hugofrias)
```

## 4. Asignación y Gestión de Contraseñas: `passwd`

Si diste de alta a **`hugofrias`** mediante `useradd`, su cuenta estará bloqueada hasta que tenga una clave asignada:

```bash
# Asignar o cambiar su contraseña:
sudo passwd hugofrias
```

### Forzar a que cambie la clave en su primer acceso

Si le diste una clave provisional, oblígalo a cambiarla nada más iniciar sesión:

```bash
sudo passwd -e hugofrias
```

*(Al conectarse por consola o SSH, el sistema le pedirá su clave actual y le forzará a escribir una nueva antes de dejarlo continuar).*

---

## 5. Modificar la Información del Usuario: `usermod`

El comando `usermod` (*user modify*) permite editar cualquier atributo de la cuenta.

### 5.1. Cambiar el nombre real o descripción (`-c`)

```bash
sudo usermod -c "Hugo Frias - Ingeniero de Software" hugofrias
```

### 5.2. Mover su carpeta personal a otra ubicación (`-d` y `-m`)

Si necesitas mover el directorio de **`hugofrias`** a otro disco (por ejemplo `/data/hugofrias`):

* **`-d`**: Establece la nueva ruta.
* **`-m`**: Traslada automáticamente todos sus archivos a esa nueva ruta.

```bash
sudo usermod -d /data/hugofrias -m hugofrias
```

---

## 6. Cambiar el Intérprete de Comandos (Shell)

### ¿Cómo saber qué shells están disponibles en el equipo?

```bash
cat /etc/shells
# Ejemplo: /bin/bash, /bin/sh, /usr/bin/zsh
```

### Cambiar la shell de `hugofrias` (por ejemplo a Zsh)

Puedes usar cualquiera de estas dos opciones:

```bash
# Opción 1: Con usermod
sudo usermod -s /usr/bin/zsh hugofrias

# Opción 2: Con chsh (Change Shell)
sudo chsh -s /usr/bin/zsh hugofrias
```

### Caso especial: Desactivar acceso interactivo a la consola

Si solo quieres que **`hugofrias`** use servicios de transferencia (como SFTP o base de datos) sin permitirle abrir una terminal:

```bash
sudo usermod -s /usr/sbin/nologin hugofrias
```

---

## 7. Añadir el Usuario a Grupos

Los grupos permiten compartir permisos (administración, contenedores, servidores web, etc.).

### 🔥 La combinación obligatoria: `-aG`

Para agregar a **`hugofrias`** a los grupos `sudo` (administrador) y `docker`:

```bash
# -a (append): Agrega al usuario SIN sacarlo de sus grupos anteriores
# -G (groups): Especifica los grupos secundarios
sudo usermod -aG sudo,docker hugofrias
```

>[!CAUTION]
> 🚨 **ADVERTENCIA:** Si olvidas la opción `-a` y solo pones `sudo usermod -G docker hugofrias`, **eliminarás a hugofrias de todos los demás grupos a los que pertenecía**, perdiendo accesos críticos como `sudo`. Usa siempre `-aG`.

### Verificar los grupos actuales

```bash
groups hugofrias
# Salida: hugofrias : hugofrias sudo docker
```

## 8. Bloquear y Desbloquear la Cuenta

Si **`hugofrias`** se ausenta temporalmente o necesitas suspender su acceso sin borrar sus datos:

### Con `passwd`

```bash
# Bloquear la cuenta (-l = lock)
sudo passwd -l hugofrias

# Desbloquear la cuenta (-u = unlock)
sudo passwd -u hugofrias
```

### Con `usermod`

```bash
sudo usermod -L hugofrias   # Bloquear
sudo usermod -U hugofrias   # Desbloquear
```

*(Internamente esto añade un símbolo `!` al hash en `/etc/shadow`, invalidando el inicio de sesión por contraseña).*

---

## 9. Eliminar la Cuenta de Usuario: `userdel`

Cuando el ciclo de vida de la cuenta concluye, dispones de dos alternativas:

### 9.1. Borrado parcial (Mantiene su carpeta personal)

```bash
sudo userdel hugofrias
```

*Borra al usuario del sistema, pero su carpeta `/home/hugofrias` se mantiene intacta en el disco.*

### 9.2. Borrado total y definitivo (`-r`)

```bash
sudo userdel -r hugofrias
```

*Elimina al usuario **y destruye permanentemente** su carpeta `/home/hugofrias` junto con su buzón de correo.*

### 💡 ¿Qué hacer si dice *"user hugofrias is currently used by process..."*?

Si Hugo dejó programas ejecutándose en segundo plano, el sistema impedirá su eliminación. Ciérralos primero:

```bash
# 1. Finalizar todos los procesos activos de hugofrias
sudo pkill -u hugofrias

# 2. Proceder con el borrado definitivo
sudo userdel -r hugofrias
```

## 10. Flujo Completo de Ejemplo en un Solo Bloque

El proceso integral para crear, configurar y verificar a **`hugofrias`**:

```bash
# 1. Crear con carpeta personal y bash
sudo useradd -m -s /bin/bash hugofrias

# 2. Asignar contraseña
sudo passwd hugofrias

# 3. Forzar renovación de clave en su primer login
sudo passwd -e hugofrias

# 4. Añadir su nombre real
sudo usermod -c "Hugo Frias" hugofrias

# 5. Darle acceso administrativo
sudo usermod -aG sudo hugofrias

# 6. Auditar la configuración resultante
id hugofrias
ls -ld /home/hugofrias
```

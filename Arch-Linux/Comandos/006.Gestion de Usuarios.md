# Gestión de Cuentas de Usuarios en Linux

Esta guía cubre todo el ciclo de vida de un usuario en Linux utilizando un único ejemplo práctico de principio a fin: el usuario **`hugofrias`**.

>[!NOTE]
> 💡 **Nota:** La administración de cuentas de usuario y la inspección de archivos protegidos requieren privilegios de superusuario (`sudo`).

---

## 1. ¿Dónde Guarda Linux la Información de los Usuarios?

Linux registra las cuentas en tres archivos de texto plano fundamentales:

1. **/etc/passwd:** Contiene los datos principales de la cuenta (nombre, identificador UID, grupo GID, carpeta personal y shell). Es legible por cualquier usuario.
2. **/etc/shadow:** Guarda los hashes cifrados de las contraseñas, fechas de expiración y bloqueos. Solo `root` tiene permisos de lectura.
3. **/etc/group:** Almacena los grupos creados en el sistema y qué usuarios pertenecen a ellos.

### Los rangos de UID (User ID)

* **UID 0:** Reservado exclusivamente para `root` (el superusuario).
* **UID 1 al 999:** Cuentas del sistema y servicios (`systemd`, `www-data`, `mysql`). No tienen sesión gráfica ni shell interactivo.
* **UID 1000 en adelante:** Cuentas de usuarios reales y humanos creados en el equipo.

## 2. Auditoría: ¿Cuántos Usuarios Existen y Cómo Buscarlos?

Antes de crear o modificar cuentas, conviene saber cómo inspeccionar el sistema.

### 2.1. ¿Cuántos usuarios hay en total?

Como cada cuenta ocupa una línea en `/etc/passwd`, usamos `wc -l`:

```bash
wc -l /etc/passwd
# Muestra el total de cuentas (incluyendo servicios del sistema)
```

### 2.2. ¿Cómo listar solo los usuarios humanos reales?

Filtramos con `awk` las cuentas cuyo UID sea igual o mayor a 1000:

```bash
awk -F: '$3 >= 1000 && $3 < 60000 { print "Usuario: " $1 " | UID: " $3 " | Home: " $6 }' /etc/passwd
```

### 2.3. ¿Cómo buscar si `hugofrias` ya existe?

* **Opción A (Recomendada con `getent`):** Consulta bases de datos locales y remotas:

  ```bash
  getent passwd hugofrias
  ```

  *(Si devuelve una línea, el usuario ya existe; si no devuelve nada, el nombre está libre).*

* **Opción B (Con `grep`):** Busca coincidencias exactas en el archivo local:

  ```bash
  grep '^hugofrias:' /etc/passwd
  ```

### 2.4. ¿Quién está conectado en este momento?

```bash
whoami    # Muestra tu usuario actual
who       # Lista qué usuarios tienen sesión abierta y desde qué terminal
w         # Muestra quién está conectado y qué comando o proceso está ejecutando
```

## 3. Creación de la Cuenta: `useradd` vs `adduser`

Existen dos herramientas para dar de alta usuarios:

### Banderas (*Flags*) principales de `useradd`

| Flag | Nombre | ¿Para qué sirve? |
| :---: | :--- | :--- |
| **`-m`** | *create-home* | Crea físicamente su carpeta personal (`/home/usuario`). |
| **`-s`** | *shell* | Define el intérprete de comandos por defecto (ej: `/bin/bash`). |
| **`-c`** | *comment* | Añade metadatos como el nombre real o puesto del usuario. |
| **`-d`** | *home-dir* | Especifica una ruta personalizada si no quieres que el home esté en `/home`. |
| **`-G`** | *groups* | Asigna grupos secundarios separados por coma. |
| **`-e`** | *expiredate* | Establece una fecha de caducidad automática de la cuenta (`AAAA-MM-DD`). |

---

### Opción A: Con `useradd` (El estándar universal en servidores)

Es el comando de bajo nivel disponible en cualquier distribución. No asume nada por defecto, así que le indicamos explícitamente sus parámetros:

```bash
# Creamos a hugofrias con home, bash y su nombre completo:
sudo useradd -m -s /bin/bash -c "Hugo Frias - Ingeniero Cloud" hugofrias
```

>[!WARNING]
> ⚠️ **Cuidado:** Si ejecutas `sudo useradd hugofrias` sin la bandera `-m`, la cuenta existirá pero **sin carpeta personal**. Al iniciar sesión, el sistema mostrará un error y lo arrojará a la raíz (`/`).

### Opción B: Con `adduser` (Asistente interactivo en Debian/Ubuntu)

Es un script guiado de alto nivel que crea la carpeta `/home/hugofrias` de forma automática y solicita la contraseña al instante:

```bash
sudo adduser hugofrias
```

## 4. ¿Cómo Comprobar si se Creó y Dónde Está su Carpeta?

Nunca asumas que el proceso terminó bien sin verificar:

### 4.1. Consultar su registro en `/etc/passwd`

```bash
grep hugofrias /etc/passwd
# O también: getent passwd hugofrias
```

**Salida desglosada:**

```text
hugofrias:x:1001:1001:Hugo Frias - Ingeniero Cloud:/home/hugofrias:/bin/bash
    ┬     ┬   ┬    ┬                 ┬                      ┬            ┬
    1     2   3    4                 5                      6            7
```

1. **Usuario:** `hugofrias`
2. **Contraseña:** `x` (protegida dentro de `/etc/shadow`)
3. **UID (User ID):** Identificador numérico del usuario (`1001`)
4. **GID (Group ID):** Identificador de su grupo primario (`1001`)
5. **Comentario/GECOS:** Nombre o cargo registrado
6. **Carpeta personal:** `/home/hugofrias`
7. **Intérprete de comandos:** `/bin/bash`

### 4.2. Verificar físicamente su carpeta personal

Comprobamos que la carpeta exista en disco y pertenezca a **`hugofrias`**:

```bash
ls -ld /home/hugofrias
# Salida esperada:
# drwxr-x--- 2 hugofrias hugofrias 4096 mar 25 10:00 /home/hugofrias
```

### 4.3. Ver su identidad y grupos con `id`

```bash
id hugofrias
# Salida: uid=1001(hugofrias) gid=1001(hugofrias) groups=1001(hugofrias)
```

## 5. Asignación y Gestión de Contraseñas: `passwd`

Si diste de alta a **`hugofrias`** mediante `useradd`, su cuenta permanecerá inactiva hasta que le asignes una clave.

### Banderas (*Flags*) de `passwd`

| Flag | ¿Para qué sirve? |
| :---: | :--- |
| *(sin flags)* | Asigna o cambia la contraseña del usuario. |
| **`-e`** | Fuerza a que la contraseña expire (obliga a cambiarla en el siguiente inicio de sesión). |
| **`-l`** | Bloquea la contraseña (*Lock*). |
| **`-u`** | Desbloquea la contraseña (*Unlock*). |
| **`-S`** | Muestra el estado de la contraseña (P = Activa, L = Bloqueada, NP = Sin clave). |
| **`-d`** | Borra la contraseña de la cuenta (**Peligro:** deja la cuenta sin clave). |

```bash
# 1. Asignar contraseña a hugofrias
sudo passwd hugofrias

# 2. Forzarlo a cambiarla la primera vez que entre
sudo passwd -e hugofrias

# 3. Auditar el estado de su contraseña
sudo passwd -S hugofrias
# Salida: hugofrias P 03/25/2026 ... (La 'P' indica que tiene una contraseña válida)
```

## 6. Modificar el Usuario y su Carpeta Personal: `usermod`

El comando `usermod` (*user modify*) permite editar los parámetros de una cuenta existente.

### Banderas (*Flags*) de `usermod`

| Flag | ¿Para qué sirve? |
| :---: | :--- |
| **`-c`** | Cambia la descripción o nombre real. |
| **`-d`** | Especifica la nueva ruta de la carpeta personal. |
| **`-m`** | **Mueve físicamente** los archivos del home viejo a la nueva ruta indicada en `-d`. |
| **`-s`** | Modifica el intérprete de comandos (Shell). |
| **`-aG`** | **Añade** a grupos secundarios sin eliminar los grupos existentes. |
| **`-l`** | Cambia el nombre de usuario de inicio de sesión (*login*). |
| **`-L`** / **`-U`** | Bloquear (*Lock*) o Desbloquear (*Unlock*) la cuenta. |

---

### 6.1. Cambiar el nombre real o descripción (`-c`)

```bash
sudo usermod -c "Hugo Frias - Tech Lead" hugofrias
```

### 6.2. Renombrar o mover la carpeta personal (Home)

>[!WARNING]
> 🚨 **¡NO USES EL COMANDO `mv` DIRECTAMENTE!**  
> Si ejecutas `sudo mv /home/hugofrias /home/hugo_dev`, habrás renombrado la carpeta en el disco, pero `/etc/passwd` seguirá apuntando a `/home/hugofrias`.  
> Al iniciar sesión, el sistema arrojará:  
> `Could not chdir to home directory /home/hugofrias: No such file or directory`  
> El usuario aterrizará en `/` sin acceso a sus archivos ni a su `.bashrc`.

#### La forma correcta (Sistema y Disco al mismo tiempo)

Combina **`-d`** (nueva ruta) con **`-m`** (trasladar archivos físicos):

```bash
sudo usermod -d /home/hugo_dev -m hugofrias
```

#### ¿Y si ya se había usado `mv` manualmente por error?

Si los archivos ya fueron movidos en el disco con `mv`, actualiza el registro de `/etc/passwd` **sin usar la `-m`**:

```bash
sudo usermod -d /home/hugo_dev hugofrias
```

## 7. Identificar y Cambiar el Intérprete de Comandos (Shell)

### 7.1. ¿Cómo saber qué shell estoy usando yo?

```bash
# Método 1: Leer la variable de entorno
echo $SHELL
# Salida típica: /bin/bash

# Método 2: Ver el proceso actual de la consola
echo $0
# Salida: bash (o -bash)
```

### 7.2. ¿Cómo saber qué shell tiene asignada `hugofrias`?

```bash
getent passwd hugofrias | cut -d: -f7
# O con grep:
grep '^hugofrias:' /etc/passwd | cut -d: -f7
```

### 7.3. Ver las shells válidas en el sistema

```bash
cat /etc/shells
# Ejemplo: /bin/bash, /usr/bin/zsh, /bin/sh
```

### 7.4. Cambiar la shell de `hugofrias`

```bash
# Opción A: Con usermod (-s)
sudo usermod -s /usr/bin/zsh hugofrias

# Opción B: Con chsh (Change Shell)
sudo chsh -s /usr/bin/zsh hugofrias
```

### 7.5. Caso de seguridad: Inhabilitar consola interactiva

Si `hugofrias` solo debe transferir archivos por SFTP o correr respaldos sin abrir una terminal:

```bash
sudo usermod -s /usr/sbin/nologin hugofrias
```

## 8. Añadir el Usuario a Grupos

Los grupos permiten gestionar accesos a recursos (administración con `sudo`, contenedores con `docker`, etc.).

### 🔥 La combinación obligatoria: `-aG`

Para integrar a **`hugofrias`** a los grupos `sudo` y `docker`:

```bash
sudo usermod -aG sudo,docker hugofrias
```

>[!CAUTION]
> 🚨 **ADVERTENCIA:** Si olvidas la opción `-a` (*append*) y solo ejecutas `sudo usermod -G docker hugofrias`, **eliminarás a hugofrias de todos los grupos secundarios que tenía asignados previamente**, perdiendo accesos críticos como `sudo`. Usa siempre `-aG`.

### Verificar los grupos asignados

```bash
groups hugofrias
# Salida: hugofrias : hugofrias sudo docker
```

## 9. Bloquear y Desbloquear la Cuenta

Si **`hugofrias`** sale de vacaciones o necesitas suspender su acceso preventivamente sin tocar sus archivos:

### Con `passwd`

```bash
# Bloquear la cuenta (-l = lock)
sudo passwd -l hugofrias

# Desbloquear la cuenta (-u = unlock)
sudo passwd -u hugofrias
```

### Con `usermod`

```bash
sudo usermod -L hugofrias   # Bloquear
sudo usermod -U hugofrias   # Desbloquear
```

*(El sistema añade un signo `!` antes del hash en `/etc/shadow`, invalidando el inicio de sesión por clave).*

## 10. Eliminar la Cuenta: `userdel` y Carpetas Modificadas

### Banderas (*Flags*) de `userdel`

| Flag | ¿Para qué sirve? |
| :---: | :--- |
| *(sin flags)* | Borra la cuenta de `/etc/passwd`, pero conserva su carpeta personal en el disco. |
| **`-r`** (*remove*) | Borra la cuenta **y destruye su carpeta home** junto con sus correos. |
| **`-f`** (*force*) | Fuerza el borrado incluso si el usuario tiene sesiones abiertas (**no recomendado**). |

---

### ¿Cómo borrar a un usuario cuya carpeta personal fue modificada?

Si a **`hugofrias`** le cambiamos su carpeta a `/home/hugo_dev` o `/data/hugofrias`, surge la duda: *¿`userdel -r` sabrá encontrarla?*

**Sí.** El comando `userdel -r` consulta la ruta actual registrada en `/etc/passwd`. Destruirá la carpeta correcta sin importar cómo se llame o en qué disco esté.

#### Flujo de borrado seguro paso a paso

>[!TIP]
> 💡 Si el sistema arroja el error: *"user hugofrias is currently used by process 1234"*, es porque dejó programas abiertos. Finalízalos primero:
>
> ```bash
> sudo pkill -u hugofrias
> ```

```bash
# 1. Comprobamos la ruta que tiene registrada actualmente
getent passwd hugofrias | cut -d: -f6
# Supongamos que nos muestra: /home/hugo_dev

# 2. Eliminamos al usuario y su carpeta de forma limpia
sudo userdel -r hugofrias

# 3. Comprobamos que no quedó rastro en el sistema ni en el disco
getent passwd hugofrias   # No debe devolver nada
ls -ld /home/hugo_dev     # Debe decir: No such file or directory
```

#### ¿Qué hacer si quedaron archivos huérfanos?

Si en el pasado se hicieron cambios manuales desordenados, pueden quedar archivos en el sistema cuyo dueño era el UID de `hugofrias`. Para rastrearlos y limpiarlos:

```bash
# Buscar archivos en el sistema sin ningún dueño registrado:
sudo find /home -nouser
```

## 11. Flujo Completo de Ejemplo en un Solo Bloque

El proceso integral para dar de alta, configurar, modificar y auditar a **`hugofrias`**:

```bash
# 1. Crear con carpeta personal y bash
sudo useradd -m -s /bin/bash hugofrias

# 2. Asignar contraseña inicial
sudo passwd hugofrias

# 3. Forzar cambio de clave en su primer acceso
sudo passwd -e hugofrias

# 4. Añadir su puesto de trabajo
sudo usermod -c "Hugo Frias - Ingeniero Cloud" hugofrias

# 5. Darle permisos de administración y contenedores
sudo usermod -aG sudo,docker hugofrias

# 6. Renombrar su carpeta de trabajo de forma limpia
sudo usermod -d /home/hugo_dev -m hugofrias

# 7. Auditar la configuración resultante
id hugofrias
getent passwd hugofrias
ls -ld /home/hugo_dev
```

# Permisos en Linux: Archivos y Directorios

En Linux, la seguridad y el control de acceso se basan en un sistema de **permisos y propietarios**. Cada archivo y carpeta tiene reglas estrictas sobre quién puede leerlo, modificarlo o ejecutarlo.

---

## PARTE 1: ¿Cómo Ver los Permisos de un Archivo o Carpeta?

Para inspeccionar los permisos existen dos comandos principales:

### 1. El estándar visual: `ls -l`

```bash
ls -l
```

Salida de ejemplo:

```text
-rwxr-xr-- 1 hugofrias10 desarrolladores 4096 mar 24 10:30 script.sh
drwxr-xr-x 2 hugofrias10 desarrolladores 4096 mar 24 10:35 proyecto
```

Si quieres ver los permisos de una carpeta específica **sin ver su contenido interior**, usa la bandera `-d`:

```bash
ls -ld /var/www/html
```

### 2. La vista técnica detallada: `stat`

`stat` muestra los permisos tanto en formato de letras como en formato numérico (octal), además de inodos y marcas de tiempo:

```bash
stat script.sh
# Muestra algo como: Access: (0754/-rwxr-xr--)  Uid: ( 1000/    hugofrias10)   Gid: ( 1000/ desarrolladores)
```

## PARTE 2: Anatomía de la Cadena de Permisos (Paso a Paso)

Al hacer `ls -l`, verás una cadena de 10 caracteres como esta:

```text
 -  r w x  r - x  r - -
─┬─ ──┬──  ──┬──  ──┬──
 0    1      2      3
```

### Paso 0: El primer carácter (Tipo de elemento)

* `-` : Es un **archivo común** (texto, imagen, binario, script).
* `d` : Es un **directorio** (*directory* / carpeta).
* `l` : Es un **enlace simbólico** (*symlink* / acceso directo).

### Pasos 1, 2 y 3: Los Tres Bloques de Sujetos

Los 9 caracteres restantes se dividen en 3 bloques de 3 letras cada uno:

| Bloque | Símbolo | ¿Quién es? | Explicación |
| :---: | :---: | :--- | :--- |
| **1** | **`u`** | **User (Propietario)** | La persona dueña del archivo (usualmente quien lo creó). |
| **2** | **`g`** | **Group (Grupo)** | Los miembros del grupo asignado a este archivo. |
| **3** | **`o`** | **Others (Otros)** | Cualquier otro usuario del sistema que no sea el dueño ni pertenezca al grupo. |
| *Todos* | **`a`** | **All (Todos)** | Representa a `u`, `g` y `o` simultáneamente. |

---

## PARTE 3: ¿Qué Significa Cada Letra (`r`, `w`, `x`, `-`)?

El significado de las letras **cambia de forma radical** si se aplica a un archivo o a una carpeta:

| Letra | Nombre | Significado en un ARCHIVO | Significado en una CARPETA |
| :---: | :--- | :--- | :--- |
| **`r`** | *Read* (Lectura) | Permite **abrir y leer** el contenido del archivo (`cat`, `less`, etc.). | Permite **listar el contenido** de la carpeta (`ls`). |
| **`w`** | *Write* (Escritura) | Permite **modificar, editar o sobrescribir** el contenido del archivo. | Permite **crear, borrar o renombrar** archivos dentro de la carpeta (¡incluso si el archivo interior no es tuyo!). |
| **`x`** | *eXecute* (Ejecución) | Permite **ejecutarlo como programa** o script (`./script.sh`). | Permite **entrar a la carpeta** (`cd`) y acceder a los archivos que contiene. |
| **`-`** | *Sin permiso* | Permiso denegado para esa acción concreta. | Permiso denegado para esa acción concreta. |

>[!DANGER]
> ⚠️ **Detalle crítico con las carpetas:**  
> Si una carpeta tiene permiso de lectura (`r`) pero NO de ejecución (`x`), podrás ver los nombres de los archivos con `ls`, pero **no podrás entrar con `cd` ni abrir ningún archivo interior**, porque `x` en directorios significa *"derecho a transitar o atravesar"*.

## PARTE 4: Cómo Leer un Permiso en la Práctica

Desglosemos el ejemplo: `-rwxr-xr--`

1. `-` : Es un archivo.
2. `rwx` : El **propietario** puede leerlo, editarlo y ejecutarlo.
3. `r-x` : El **grupo** puede leerlo y ejecutarlo, pero **no** modificarlo.
4. `r--` : El resto del mundo (**otros**) solo puede leerlo.

Otro ejemplo: `drwxr-x---`

1. `d` : Es una carpeta.
2. `rwx` : El **propietario** puede ver archivos, entrar y crear/borrar cosas.
3. `r-x` : El **grupo** puede ver archivos y entrar con `cd`, pero no crear ni borrar.
4. `---` : Los **demás usuarios** no tienen acceso alguno (no pueden ni ver si hay algo dentro).

## PARTE 5: Método 1 — Cambiar Permisos con Letras (Simbólico)

El comando para modificar permisos es `chmod` (*Change Mode*).

La sintaxis del modo simbólico es:
$$\text{chmod } [\text{A quién}] [\text{Acción}] [\text{Permiso}] \text{ archivo}$$

* **A quién:** `u` (dueño), `g` (grupo), `o` (otros), `a` (todos).
* **Acción:** `+` (dar permiso), `-` (quitar permiso), `=` (fijar exactamente ese permiso).
* **Permiso:** `r`, `w`, `x`.

### Ejemplos prácticos

```bash
# 1. Dar permiso de ejecución al dueño para correr un script:
chmod u+x script.sh

# 2. Quitar permisos de escritura al grupo y a otros (evitar que lo modifiquen):
chmod go-w informe.docx

# 3. Dar permiso de lectura a todo el mundo (a = all):
chmod a+r publico.txt

# 4. Asignar permisos exactos: el dueño todo, el grupo nada:
chmod u=rwx,g=,o= secreto.txt
```

## PARTE 6: Método 2 — Permisos con Números (Notación Octal)

En la administración de sistemas se usa habitualmente la notación numérica por rapidez. Cada letra tiene un valor matemático binario:

| Permiso | Letra | Valor Numérico |
| :--- | :---: | :---: |
| **Lectura** | `r` | **4** |
| **Escritura** | `w` | **2** |
| **Ejecución** | `x` | **1** |
| **Ninguno** | `-` | **0** |

Para formar el número de un bloque, **sumas los valores**:

* `r w x` = $4 + 2 + 1 = \mathbf{7}$ (Control total)
* `r w -` = $4 + 2 + 0 = \mathbf{6}$ (Lectura y escritura)
* `r - x` = $4 + 0 + 1 = \mathbf{5}$ (Lectura y ejecución)
* `r - -` = $4 + 0 + 0 = \mathbf{4}$ (Solo lectura)
* `- - -` = $0 + 0 + 0 = \mathbf{0}$ (Sin ningún permiso)

Un permiso completo se expresa con **3 dígitos** (uno para `u`, otro para `g` y otro para `o`):

```text
     u     g     o
    rwx   r-x   r--
    4+2+1 4+0+1 4+0+0
      7     5     4   ==> chmod 754 archivo
```

### Las combinaciones numéricas más comunes en Linux

* **`chmod 644 archivo.txt`** (Estándar para archivos):  
  Dueño: lectura y escritura (`6`). Grupo y otros: solo lectura (`4`).
* **`chmod 755 carpeta/`** (Estándar para carpetas y scripts):  
  Dueño: todo (`7`). Grupo y otros: listar y entrar (`5`).
* **`chmod 700 clave_ssh`** (Privacidad total):  
  Solo el dueño tiene acceso (`7`). Grupo y otros: nada (`0`).
* **`chmod 777 elemento`** (Peligro):  
  Cualquiera en la máquina puede leer, escribir, ejecutar o borrar. **Evita usar 777 en producción.**

## PARTE 7: ¿Cómo Modificar Solo la Carpeta y NO su Contenido?

Por diseño predeterminado, `chmod` **solo afecta a la carpeta en sí misma** y no toca los archivos de adentro:

```bash
# Solo cambia los permisos de la carpeta 'fotos', su contenido queda intacto:
chmod 750 fotos
```

### ¿Y si quieres que afecte a la carpeta y a todo lo de adentro?

Para eso debes usar la bandera recursiva **`-R`** (mayúscula):

```bash
# Cambia los permisos de la carpeta y de todos sus archivos y subcarpetas:
chmod -R 755 mi_proyecto
```

---

### 🔥 El truco maestro: Dar permisos solo a carpetas o solo a archivos recursivamente

Un problema común con `chmod -R` es que si aplicas `chmod -R 755`, le darás permiso de ejecución (`x`) a documentos de texto plano que no deberían ser ejecutables. Para solucionar esto existen dos métodos:

#### Opción A: La `X` mayúscula inteligente

La bandera `X` mayúscula aplica el permiso de ejecución **únicamente a directorios**, ignorando los archivos regulares:

```bash
# Hace navegables todas las carpetas sin volver ejecutables los archivos de texto:
chmod -R a+rX mi_proyecto/
```

#### Opción B: Con el comando `find` (Control absoluto)

Es el método preferido por los administradores de sistemas:

```bash
# 1. Cambiar SOLO las carpetas a 755 recursivamente:
find /var/www/sitio -type d -exec chmod 755 {} +

# 2. Cambiar SOLO los archivos a 644 recursivamente:
find /var/www/sitio -type f -exec chmod 644 {} +
```

## PARTE 8: Cambiar el Dueño y Grupo (`chown` y `chgrp`)

Los permisos de nada sirven si el archivo pertenece al usuario equivocado.

* **`chown`** (*Change Owner*): Cambia el usuario dueño y/o el grupo.
* **`chgrp`** (*Change Group*): Cambia únicamente el grupo.

```bash
# 1. Cambiar solo el usuario propietario:
sudo chown hugofrias10 reporte.pdf

# 2. Cambiar el usuario Y el grupo simultáneamente (usuario:grupo):
sudo chown hugofrias10:hugofrias10 reporte.pdf

# 3. Cambiar de forma recursiva a toda una carpeta:
sudo chown -R hugofrias10:hugofrias10 /var/www/html

# 4. Cambiar solo el grupo:
sudo chgrp hugofrias10 datos.csv
```

## PARTE 9: Permisos Especiales (Mención Rápida)

En sistemas avanzados existen permisos adicionales que sustituyen las letras habituales:

* **Sticky Bit (`t` al final, ej: `drwxrwxrwt`):**  
  Usado en carpetas compartidas como `/tmp`. Permite que todos escriban archivos, pero **solo el creador de un archivo puede borrarlo**.

  ```bash
  chmod +t /carpeta_compartida  # o numéricamente: chmod 1777 /carpeta
  ```

* **SUID (`s` en el usuario, ej: `-rwsr-xr-x`):**  
  El archivo se ejecuta siempre con los privilegios del dueño (como el comando `passwd`).
* **SGID (`s` en el grupo, ej: `drwxr-sr-x`):**  
  Los archivos nuevos creados dentro de la carpeta heredan automáticamente el grupo de dicha carpeta.

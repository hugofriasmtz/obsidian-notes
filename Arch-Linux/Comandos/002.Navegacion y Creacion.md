# Navegación y Creación en Linux (Directorios y Archivos)

Esta guía cubre los comandos esenciales para moverte por el árbol de directorios de Linux y los métodos para crear tanto carpetas como archivos (vacíos o con contenido), incluyendo trucos avanzados de expansión de la terminal.

---

## PARTE 1: Conceptos Básicos de Rutas

Antes de navegar, es clave entender los símbolos especiales de Linux:

| Símbolo | Significado |
| :--- | :--- |
| `/` | **Raíz (Root):** El origen de todo el sistema de archivos. |
| `~` | **Home:** Tu directorio personal de usuario (ej. `/home/juan`). |
| `.` | **Directorio actual:** La carpeta donde estás ubicado en este momento. |
| `..` | **Directorio padre:** La carpeta que está un nivel por encima. |
| `-` | **Directorio anterior:** El último directorio en el que estuviste parado. |

* **Ruta absoluta:** Empieza siempre desde la raíz (`/var/log/nginx`).
* **Ruta relativa:** Empieza desde donde te encuentras actualmente (`./documentos` o `../fotos`).

---

## PARTE 2: Navegación por el Sistema

### 1. ¿Dónde estoy parado?: `pwd`

`pwd` (*Print Working Directory*) imprime la ruta absoluta del directorio actual.

```bash
pwd
# Ejemplo de salida: /home/usuario/proyectos
```

* **`-P`**: Muestra la ruta física real si estás dentro de un enlace simbólico (*symlink*).

  ```bash
  pwd -P
  ```

---

### 2. Moverse entre carpetas: `cd`

`cd` (*Change Directory*) permite cambiar la ubicación actual.

#### Usos básicos y atajos indispensables

```bash
# 1. Ir a tu carpeta personal (Home)
cd ~
# o simplemente:
cd

# 2. Subir un nivel (al directorio padre)
cd ..

# 3. Subir dos niveles hacia arriba
cd ../..

# 4. Volver al directorio donde estabas antes (como el botón "atrás" de un navegador)
cd -

# 5. Ir a una ruta absoluta
cd /var/www/html

# 6. Ir a una ruta con espacios en el nombre (usa comillas o barra invertida)
cd "Mis Documentos"
cd Mis\ Documentos
```

---

### 3. Navegación avanzada con pila: `pushd` y `popd`

Cuando tienes que saltar temporalmente a una carpeta muy lejana y luego regresar sin perderte:

* **`pushd <ruta>`**: Guarda tu directorio actual en una pila de memoria y salta a la nueva ruta.
* **`popd`**: Elimina la última ruta guardada y te regresa exactamente a ella.

```bash
# Supón que estás en /home/usuario/proyectos
pushd /etc/nginx/conf.d   # Vas a Nginx, pero se recuerda tu origen
# Haces tus configuraciones...
popd                      # Regresas automáticamente a /home/usuario/proyectos
```

## PARTE 3: Creación de Directorios (`mkdir`)

El comando `mkdir` (*Make Directory*) se utiliza para generar carpetas.

### 1. Creación básica

```bash
# Crear un solo directorio
mkdir proyectos

# Crear múltiples directorios a la vez
mkdir css js imagenes
```

---

### 2. Creación recursiva / anidada: `-p`

Si intentas crear `carpeta1/carpeta2` y `carpeta1` no existe, Linux dará error. La bandera `-p` (*parents*) crea toda la ruta intermedia sin fallar:

```bash
mkdir -p app/src/controllers
```

---

### 3. Asignar permisos al crear: `-m`

Permite fijar los permisos octales de la carpeta desde el momento en que se genera.

```bash
# Crea una carpeta accesible solo para el propietario (rwx------)
mkdir -m 700 carpeta_privada
```

---

### 4. Magia de Bash: Expansión de llaves

Crea estructuras complejas en un solo comando combinando `-p` con `{ }`:

```bash
# Crea una estructura completa de proyecto en un segundo:
mkdir -p mi_proyecto/{src/{css,js,views},public,tests,docs}
```

## PARTE 4: Creación de Archivos

En Linux no existe un solo comando exclusivo para "crear archivos", sino varias formas según el objetivo:

### 1. Archivos vacíos o actualizar fecha: `touch`

Es el método estándar más rápido para crear archivos vacíos. Si el archivo ya existe, actualiza su marca de fecha y hora sin modificar su contenido.

```bash
# Crear un archivo vacío
touch notas.txt

# Crear múltiples archivos
touch index.html estilos.css script.js

# Crear varios archivos con nombres numerados
touch reporte_{1..5}.txt    # Crea: reporte_1.txt, reporte_2.txt ... reporte_5.txt
```

---

### 2. Creación con redirección (`>`, `>>`)

Permite crear un archivo directamente con contenido desde la salida de otro comando:

* **`>` (Sobrescribe / Crea):** Si el archivo existe lo borra y lo reemplaza; si no, lo crea.
* **`>>` (Añade / Concatena):** Agrega texto al final del archivo sin borrar lo existente.

```bash
# Crear un archivo con texto simple
echo "Servidor de pruebas v1.0" > config.txt

# Agregar una nueva línea
echo "Modo debug: activo" >> config.txt

# Crear un archivo completamente vacío (truco rápido usando salida nula)
> archivo_vacio.txt
```

---

### 3. Crear archivos de múltiples líneas en consola (*Heredoc*)

Ideal para scripts o para redactar configuraciones completas de golpe usando `cat`:

```bash
cat <<EOF > docker-compose.yml
version: '3.8'
services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
EOF
```

---

### 4. Crear archivos de tamaño fijo para pruebas

Útil para simular cargas de disco, límites de cuota o descargas de red:

```bash
# 1. Método rápido (no asigna bloques de disco reales al instante)
truncate -s 100M archivo_grande.zip

# 2. Asignando espacio físico real en disco de inmediato
fallocate -l 1G archivo_1gb.img

# 3. Creando un archivo con ceros binarios reales (compatible con cualquier Unix)
dd if=/dev/zero of=datos_prueba.bin bs=1M count=50
```

## PARTE 5: Flujo de Trabajo Combinado (Ejemplo Práctico)

Así se combinan navegación, creación de carpetas y archivos en una sesión habitual:

```bash
# 1. Nos aseguramos de estar en nuestro home
cd ~

# 2. Creamos una estructura completa de trabajo
mkdir -p workspace/sitio_web/{css,js,img}

# 3. Navegamos al proyecto recién creado
cd workspace/sitio_web

# 4. Creamos los archivos iniciales
touch index.html css/styles.css js/app.js

# 5. Escribimos algo en el archivo principal
echo "<h1>Sitio Web Listo</h1>" > index.html

# 6. Comprobamos la estructura resultante con navegación relativa
pwd
ls -R
```

## PARTE 6: Tabla Resumen (Cheat Sheet)

| Tarea | Comando / Ejemplo |
| :--- | :--- |
| **Saber dónde estás** | `pwd` |
| **Ir al Home personal** | `cd` o `cd ~` |
| **Subir un nivel** | `cd ..` |
| **Regresar a la carpeta previa** | `cd -` |
| **Crear una carpeta** | `mkdir nombre_carpeta` |
| **Crear carpetas anidadas** | `mkdir -p ruta/a/subcarpeta` |
| **Crear lote de carpetas** | `mkdir -p modulo/{v1,v2}/{db,api}` |
| **Crear archivo vacío** | `touch archivo.txt` |
| **Crear lote de archivos** | `touch file_{A,B,C}.log` |
| **Crear archivo con texto** | `echo "contenido" > archivo.txt` |
| **Agregar texto a un archivo** | `echo "más contenido" >> archivo.txt` |
| **Crear archivo de 50MB (pruebas)** | `fallocate -l 50M test.img` |

# Contenido y Comparación de Archivos en Linux

Esta guía cubre las herramientas esenciales para dos tareas críticas:

1. **Visualización y Lectura:** Volcar, paginar, monitorear en tiempo real y extraer datos de archivos por líneas o bytes.
2. **Comparación e Integridad:** Detectar diferencias entre archivos (por líneas, formato de contexto, bytes) y comprobar su integridad con sumas de comprobación (*hashes*).

---

## PARTE 1: Visualización y Lectura de Contenido

### 1. Salida completa: `cat` y `tac`

#### `cat` (*Concatenate*)

Imprime todo el contenido del archivo directamente en la terminal.
>[!WARNING]
> ⚠️ **Precaución:** Úsalo con archivos medianos o pequeños. Abrir archivos gigantescos con `cat` saturará tu terminal.

```bash
cat config.env
```

* **`-n`**: Muestra los números de línea (incluyendo líneas vacías).

  ```bash
  cat -n script.py
  ```

* **`-b`**: Numera solo las líneas que **no** están vacías.

  ```bash
  cat -b notas.txt
  ```

* **`-s`**: Comprime múltiples líneas vacías consecutivas en una sola.

  ```bash
  cat -s archivo_espaciado.txt
  ```

#### `tac` (*cat invertido*)

Lee e imprime las líneas en **orden inverso** (de la última línea a la primera).

```bash
tac historial.log
```

---

### 2. Lectura paginada interactiva: `less` y `more`

Permiten inspeccionar archivos largos cómodamente sin saturar la memoria RAM.

* **`more`**: Es el visor tradicional. Solo permite avanzar hacia adelante línea a línea o pantalla por pantalla.
* **`less`**: Es el estándar moderno (*"less is more"*). Permite desplazarse bidireccionalmente y realizar búsquedas de texto.

```bash
less /var/log/syslog
```

#### Atajos clave dentro de `less`

| Tecla | Acción |
| :--- | :--- |
| `Espacio` o `f` | Avanzar una página. |
| `b` | Retroceder una página. |
| `Enter` o Flecha abajo | Avanzar una línea. |
| `g` / `G` | Ir al inicio (`g`) o al final (`G`) del archivo. |
| `/término` | Buscar una palabra hacia adelante (`n` siguiente, `N` anterior). |
| `q` | Salir del visor. |

---

### 3. Lectura parcial: `head` y `tail`

Permiten extraer fracciones de un archivo, ya sea por **número de líneas** o por **bytes/caracteres exactos**.

#### `head` (Muestra el inicio del archivo)

Por defecto muestra las primeras 10 líneas.

* **Por líneas (`-n`)**:

  ```bash
  head -n 25 datos.csv       # Primeras 25 líneas
  ```

* **Por bytes/caracteres (`-c`)**:

  ```bash
  head -c 100 archivo.txt     # Primeros 100 bytes del archivo
  # Generar una clave aleatoria rápida combinándolo con /dev/urandom:
  head -c 16 /dev/urandom | base64
  ```

---

#### `tail` (Muestra el final del archivo)

Por defecto muestra las últimas 10 líneas.

* **Por líneas (`-n`)**:

  ```bash
  tail -n 50 error.log       # Últimas 50 líneas
  ```

* **Por bytes/caracteres (`-c`)**:

  ```bash
  tail -c 80 error.log       # Últimos 80 bytes
  tail -c +101 binario.dat   # Lee DESDE el byte 101 hasta el final
  ```

#### 🔥 Monitoreo en tiempo real: `tail -f`

Mantiene el archivo abierto y muestra en pantalla las nuevas líneas a medida que se escriben (imprescindible para monitorear servidores):

```bash
tail -f /var/log/nginx/access.log
# Presiona Ctrl + C para salir
```

---

### 4. Conteo de contenido: `wc`

`wc` (*Word Count*) analiza el volumen de texto o datos de un archivo.

```bash
wc archivo.txt
# Salida: 45  180 1200 archivo.txt (Líneas, Palabras, Bytes)
```

* **`-l`**: Cuenta únicamente el número de **líneas**.

  ```bash
  wc -l base_datos.csv
  ```

* **`-w`**: Cuenta únicamente el total de **palabras**.
* **`-c`**: Cuenta el tamaño total en **bytes**.

  ```bash
  wc -c imagen.iso
  ```

## PARTE 2: Comparación de Archivos

### 1. Comparación línea a línea: `diff`

Identifica las diferencias entre dos archivos de texto.

```bash
diff archivo1.txt archivo2.txt
```

#### Formatos de salida y banderas clave de `diff`

* **`-u` (Formato unificado):** El estándar moderno utilizado por Git y desarrolladores. Muestra las líneas añadidas con `+` y las eliminadas con `-`.

  ```bash
  diff -u config_v1.ini config_v2.ini
  ```

* **`-c` (Formato de contexto):** El formato histórico tradicional de Unix. Muestra bloques separados para cada archivo con marcas contextuales:
  * `+` : Línea agregada.
  * `-` : Línea eliminada.
  * `!` : Línea modificada.

  ```bash
  diff -c version1.txt version2.txt
  ```

* **`-y` (En paralelo / dos columnas):**

  ```bash
  diff -y archivo1.txt archivo2.txt
  ```

* **`-w` (Ignorar espacios):** Omite discrepancias de espacios en blanco o tabulaciones.

  ```bash
  diff -uw archivo1.txt archivo2.txt
  ```

---

### 2. Comparación interactiva y visual: `sdiff` y `vimdiff`

* **`sdiff`**: Muestra las columnas en paralelo con marcadores gráficos (`|`, `<`, `>`).

  ```bash
  sdiff archivoA.txt archivoB.txt
  ```

* **`vimdiff`**: Divide la pantalla de la terminal en dos columnas coloreadas dentro de Vim:

  ```bash
  vimdiff config1.conf config2.conf
  ```

---

### 3. Comparación binaria o byte a byte: `cmp`

Ideal para saber de inmediato si dos archivos (imágenes, binarios, zips) son exactamente iguales sin procesar todo el texto.

```bash
cmp archivo1.png archivo2.png
# Si son iguales: No imprime nada (retorna código 0)
# Si difieren: Indica el número de byte y línea donde difieren
```

* **`-c`**: Muestra los **caracteres ASCII** que difieren en lugar de solo los números de posición en bytes.

  ```bash
  cmp -c archivo1.txt archivo2.txt
  ```

---

### 4. Comparación de listas ordenadas: `comm`

Compara dos archivos previamente ordenados (`sort`) y los muestra en 3 columnas: líneas exclusivas de A, exclusivas de B y comunes a ambos.

```bash
# Mostrar SOLO las líneas idénticas que comparten ambos archivos (-12 suprime las columnas 1 y 2):
comm -12 lista_A_ordenada.txt lista_B_ordenada.txt
```

---

### 5. Verificación por Hash criptográfico (Checksums)

La forma infalible de garantizar que dos archivos son clones exactos, incluso a través de la red o descargas:

```bash
sha256sum archivo_original.iso
sha256sum archivo_descargado.iso
```

Si ambos hashes alfanuméricos coinciden carácter por carácter, la integridad es del 100%.

## PARTE 3: Tabla Resumen (Cheat Sheet)

| Tarea | Comando / Ejemplo |
| :--- | :--- |
| **Imprimir todo el archivo** | `cat archivo.txt` |
| **Ver archivo con números de línea** | `cat -n script.py` |
| **Leer en orden inverso (abajo hacia arriba)** | `tac historial.log` |
| **Navegar cómodamente por páginas** | `less /var/log/syslog` |
| **Ver las primeras $N$ líneas** | `head -n 20 archivo.txt` |
| **Ver los primeros $N$ bytes** | `head -c 100 archivo.bin` |
| **Ver las últimas $N$ líneas** | `tail -n 20 archivo.txt` |
| **Ver los últimos $N$ bytes** | `tail -c 50 archivo.txt` |
| **Monitorear en tiempo real (logs)** | `tail -f /var/log/nginx/access.log` |
| **Contar líneas de un archivo** | `wc -l archivo.csv` |
| **Contar bytes exactos de un archivo** | `wc -c archivo.bin` |
| **Comparar con formato unificado** | `diff -u config_v1.txt config_v2.txt` |
| **Comparar con formato de contexto** | `diff -c version1.txt version2.txt` |
| **Comparar ignorando espacios** | `diff -uw archivoA.txt archivoB.txt` |
| **Comparación visual en columnas** | `sdiff archivoA.txt archivoB.txt` |
| **Comparar bytes y ver caracteres distintos** | `cmp -c archivoA.txt archivoB.txt` |
| **Verificar copia exacta por hash** | `sha256sum archivo.iso` |

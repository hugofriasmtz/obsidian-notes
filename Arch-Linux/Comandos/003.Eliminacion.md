# Guía Definitiva de Eliminación en Linux: Comandos, Banderas y Seguridad

>[!WARNING]
> ⚠️ **ADVERTENCIA CRÍTICA:**  
> A diferencia de los entornos gráficos (Windows, macOS o escritorios de Linux), **la terminal no tiene papelera de reciclaje por defecto**. Cuando eliminas un archivo o carpeta mediante la consola, el puntero del inodo se destruye de inmediato y recuperar los datos es complejo o prácticamente imposible.

---

## 1. Eliminar Archivos Simples: `rm`

El comando fundamental para borrar archivos es `rm` (*remove*).

### 1.1. Uso básico

```bash
# Eliminar un solo archivo
rm documento.txt

# Eliminar múltiples archivos específicos
rm foto1.jpg foto2.jpg notas.txt
```

---

### 1.2. Banderas de Seguridad (Confirmación interactiva)

- **`-i` (modo interactivo estricto):** pregunta antes de borrar **cada uno** de los archivos (`y` para sí, `n` para no).

  ```bash
  rm -i archivo_importante.txt
  # Salida: rm: remove regular file 'archivo_importante.txt'?
  ```

- **`-I` (confirmación inteligente):** pide confirmación una sola vez si vas a borrar más de 3 archivos o si borras recursivamente. Es menos invasivo que `-i`:

  ```bash
  rm -I *.log
  ```

---

### 1.3. Forzar eliminación e ignorar errores: `-f`

- **`-f` (`--force`):** ignora advertencias, suprime peticiones de confirmación y no muestra un error si el archivo especificado no existe.

  ```bash
  rm -f archivo_bloqueado.txt
  ```

---

### 1.4. Modo explicativo / Verbose: `-v`

- **`-v` (`--verbose`):** imprime en pantalla cada archivo que se va eliminando. Es útil para saber con certeza qué se borró:

  ```bash
  rm -v *.tmp
  # Salida:
  # removed 'cache1.tmp'
  # removed 'cache2.tmp'
  ```

---

## 2. Eliminar Directorios (Carpetas)

En Linux no puedes usar un simple `rm carpeta/` directo; el sistema te responderá con el error: `rm: cannot remove 'carpeta': Is a directory`.

Para carpetas existen dos enfoques:

### 2.1. El método seguro (Solo carpetas vacías): `rmdir`

Si la carpeta contiene aunque sea un archivo oculto, este comando fallará protegiendo tus datos.

```bash
# Borra la carpeta SOLO si está 100% vacía
rmdir carpeta_vacia

# Borrar jerarquías completas vacías (-p / parents)
# Si 'hijo' y 'padre' quedan vacíos, borra ambos:
rmdir -p padre/hijo
```

---

### 2.2. El método recursivo: `rm -r` o `rm -R`

Elimina la carpeta seleccionada **junto con todo su contenido** (subcarpetas, archivos y archivos ocultos).

```bash
rm -r mi_proyecto
```

---

### 2.3. El temido y poderoso: `rm -rf`

Combina recursividad (`-r`) y forzado (`-f`). Borra carpetas enteras de inmediato sin pedir confirmación bajo ninguna circunstancia.

```bash
rm -rf carpeta_pesada
```

#### 🚨 Anatomía del desastre: Por qué tenerle extremo respeto a `rm -rf`

Un simple espacio en blanco accidental puede destruir tu sistema operativo o tus datos personales:

```bash
# Lo que querías hacer (borrar la carpeta temporal dentro de tu home):
rm -rf /home/usuario/tmp

# El error fatal (un espacio accidental entre '/' y 'home'):
rm -rf / home/usuario/tmp
#        ^ ¡Esto le ordena borrar la raíz del sistema completo!
```

> **Nota de seguridad del núcleo:** En las distribuciones modernas de Linux, el comando `rm -rf /` está bloqueado por defecto gracias a la bandera interna `--preserve-root`. Sin embargo, esto no te salvará si borras por error carpetas como `/var`, `/home` o `/etc`.

## 3. Borrado con Patrones y Comodines (*Wildcards*)

Es común querer limpiar muchos archivos con extensiones específicas:

```bash
# Borra todos los archivos que terminen en .log
rm *.log

# Borra archivos temporales que inicien con "temp_"
rm temp_*
```

### 💡 La Regla de Oro antes de usar comodines con `rm`

Antes de ejecutar una eliminación masiva basada en `*`, ejecuta primero un `ls` con exactamente el mismo patrón. Si la salida es la correcta, sustituye `ls` por `rm`:

```bash
# Paso 1: Inspeccionar
ls -l *.bak

# Paso 2: Solo si la lista anterior es correcta, ejecutar:
rm *.bak
```

---

## 4. Borrado Seguro y Definitivo: `shred`

Cuando usas `rm`, el sistema solo marca el espacio como "disponible", pero los datos magnéticos o binarios siguen existiendo físicamente en el disco hasta que se sobrescriban (pudiendo recuperarse con herramientas forenses).

Si vas a desechar claves privadas, contraseñas o datos confidenciales, usa `shred`:

```bash
shred -u -z -n 3 claves_bancarias.txt
```

- **`-n 3`**: sobrescribe el archivo 3 veces con patrones de datos aleatorios.
- **`-z`**: añade una última pasada escribiendo ceros (`0x00`) para camuflar el triturado.
- **`-u`**: desvincula y elimina el archivo una vez sobrescrito.

---

## 5. Búsqueda y Borrado Masivo con `find`

Cuando necesitas borrar archivos según condiciones específicas (antigüedad, tamaño, etc.):

```bash
# 1. Borrar todos los archivos con extensión .log modificados hace más de 30 días
find /var/log/app -name "*.log" -mtime +30 -type f -delete

# 2. Encontrar y borrar todos los directorios que estén vacíos
find . -type d -empty -delete
```

>[!TIP]
> **Nota:** ejecuta primero el comando `find` sin la opción `-delete` para comprobar qué archivos va a borrar.

## 6. Buenas Prácticas: Crear una "Papelera" en la Terminal

Si quieres evitar tragedias, existen dos estrategias recomendadas:

### Opción A: Proteger tu usuario mediante Alias (en `~/.bashrc`)

Agrega esta línea a tu archivo de configuración de terminal:

```bash
alias rm='rm -I --preserve-root'
```

Así, cada vez que intentes borrar más de 3 elementos o una carpeta recursiva, el sistema te obligará a escribir `y` para confirmar.

### Opción B: Instalar `trash-cli` (Papelera real para consola)

Permite enviar archivos a la papelera del sistema para poder restaurarlos si te equivocas:

```bash
# En Ubuntu/Debian: sudo apt install trash-cli

# Uso diario:
trash-put archivo.txt      # Mueve el archivo a la papelera
trash-list                 # Muestra qué hay en la papelera
trash-restore              # Te da un menú interactivo para recuperar archivos
trash-empty                # Vacía la papelera
```

| :--- | :--- | :---: |
| **Borrar un archivo** | `rm archivo.txt` | 🟡 Medio |
| **Borrar con confirmación interactiva** | `rm -i archivo.txt` | 🟢 Seguro |
| **Borrar confirmando solo lotes grandes** | `rm -I *.log` | 🟢 Seguro |
| **Forzar borrado de archivo sin avisos** | `rm -f archivo.txt` | 🟡 Medio |
| **Borrar carpeta SOLO si está vacía** | `rmdir carpeta_vacia` | 🟢 Muy seguro |
| **Borrar carpeta y contenido (preguntando)** | `rm -ri carpeta/` | 🟢 Seguro |
| **Borrar carpeta y contenido (sin preguntar)** | `rm -rf carpeta/` | 🔴 **Peligroso** |
| **Sobrescribir y destruir datos confidenciales** | `shred -u -z -n 3 secreto.txt` | 🔴 Definitivo |
| **Borrar archivos vacíos recursivamente** | `find . -type f -empty -delete` | 🟡 Medio |

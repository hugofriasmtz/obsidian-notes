# Obsidian 

Este repositorio tiene el fin de ser mi **baul** de mis notas o documentacion que recolecte en mi día a día aparte de ser mi copia de seguridad para mis diferentes dispositivos o entornos de desarrollo 

## Mi orden

Todas las carpetas que cree son intuitivas , es decir si quiero recordar que tengo instalado en mi sistema operativo que estoy ocupando en este momento o de pronto recordar mis guias de "x" cosa

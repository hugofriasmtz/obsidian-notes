# Obsidian

![Logotipo de Obsidian](https://upload.wikimedia.org/wikipedia/commons/1/10/2023_Obsidian_logo.svg)

Este repositorio tiene el fin de ser mi **baúl** de mis notas o documentación que recolecte en mi día a día aparte de ser mi copia de seguridad para mis diferentes dispositivos o entornos de desarrollo

## Navegación

Todas las carpetas que cree son intuitivas , es decir si quiero recordar que tengo instalado en mi sistema operativo que estoy ocupando en este momento o de pronto recordar mis guías de **"x"** cosa, la idea es crear un cerebro digital 🧠🤖
